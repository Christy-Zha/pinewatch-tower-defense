# 松境守卫 · Pinewatch

一款可以在桌面和手机浏览器中直接玩的中文 3D 塔防游戏。跟随弓手阿遥守住八章战役，从松风前哨一路打到晨钟王城。

**[在线游玩《松境守卫》](https://christy-zha.github.io/pinewatch-tower-defense/)**

![阿遥和两名敌将的游戏实机画面](assets/characters.jpg)

## 玩法

1. 在建造工坊选择箭塔、炮塔或寒霜法塔，再点地图上的「＋」布防。
2. 点「开始第 1 波」迎敌。阿遥会自动瞄准、拉弓和放箭。点击已建造的塔可以升级或拆除。
3. 通关结余会存入旅行钱包，可以在渡鸦商店购买战术手牌和永久装扮。

首次点击游戏即可启用音效。可以暂停、变速、全屏或选择「本局重来」。进入角色图鉴，拖动模型可以从不同角度观看阿遥射箭。

手机竖屏会沿进攻路线纵向展示地图。单指拖动旋转，双指张合缩放，点「视角」可恢复全图。地图下方可以切换建造工坊、战术手牌和敌情；转到横屏后，这些指令会移到右侧。

## 存档与本地游玩

游戏自动将进度保存在当前浏览器中。网页版和本地文件各自保存进度。要离线游玩，可下载仓库 ZIP，解压后打开根目录的 `index.html`。
