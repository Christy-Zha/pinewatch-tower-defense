# 松境守卫 · Pinewatch

一款可以在桌面和手机浏览器中直接玩的中文 3D 塔防游戏。和弓手阿遥走过二十关。守住晨钟王城后，沿盐路穿过流金沙海、月汐海岸与云上群峰，在长明峰顶点亮归途灯。

## 玩法

1. 点路旁空地或「布防」显示虚线网格，再点浅色可用格子选择塔型。红色格子被道路、河流、树石或建筑占用。所有新塔都会对齐格子中心。点树木花 4 军费移除，石块花 6 军费清除。道路、河道和建筑需要留空。引雷塔会连锁三敌，荆毒塔持续施毒，破甲重弩优先狙击重甲。
2. 点「开始第 1 波」迎敌。阿遥会自动瞄准、拉弓和放箭。点击已建造的塔可以升级或拆除。
3. 点物资箱让附近的塔转火，再点一次即可恢复守路。清箱会获得军费并腾出塔位。战场上的「物资」可以查看耐久或直接下令。两箱全清并守住城门，就能在战役纪事中点亮本章勋章。
4. 通关结余会存入旅行钱包，可以在渡鸦商店购买战术手牌和永久装扮。

每章从三位幸存者和一座一级熔炉开始。点战场上的「营地」分配伐木和采石岗位，每人每次开波产出两份对应资源。清树另得四木，碎石另得三石。每第三波有暴风雪，缺柴会拖慢塔的射速，战时砍树可以恢复供暖。守住有供暖的风雪波后可接纳幸存者，高级熔炉还会修复城门。

首次点击游戏即可启用音效。可以暂停、变速、全屏或选择「本局重来」。进入角色图鉴，拖动模型可以从不同角度观看阿遥射箭。

手机打开即进入横屏战场。即使浏览器保持竖屏，游戏也会将地图、菜单和建塔按钮一起旋转。点空地打开网格，再选格子和塔型，点已有塔可升级或拆除。右上角菜单可暂停、查看敌情、使用手牌、进入商店或重开战役。支持系统全屏的浏览器还可以在菜单中隐藏浏览器工具栏。

在菜单中点「退出全屏」可返回普通页面。单指拖动旋转，双指张合缩放，点「视角」可恢复全图。

iPhone 上想隐藏 Safari 地址栏，可以从分享菜单选择「添加到主屏幕」，开启「作为网页 App 打开」。从主屏幕启动后横放手机，地形会一直延伸到屏幕四边。

开局赠塔已改为 60 军费，第一座塔由玩家选格建造。旧战局已造好的塔沿用原位置，拆除后重新建造会对齐网格。

## 存档与本地游玩

游戏自动将进度保存在当前浏览器中。网页版和本地文件各自保存进度。要离线游玩，可下载仓库 ZIP，解压后打开根目录的 `index.html`。

「本局重来」可重新布防当前章节。「战役纪事」和「本局重来」菜单中另有「全部重来」，确认后会清空当前浏览器里的战役进度和购买记录，从第一章重新开始。
